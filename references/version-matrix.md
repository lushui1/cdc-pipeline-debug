# Flink CDC 版本兼容性速查

> 本文件作为 cdc-pipeline-debug Skill 的参考素材，Agent 在排查版本兼容性问题时按需读取。
> 来源：Flink CDC 官方文档 §概述 → Supported Flink Versions

| CDC 版本 | 兼容 Flink 版本 | 生产建议 |
|----------|----------------|----------|
| 3.6.* | 1.20.*, 2.2.* | 最新稳定版 |
| 3.5.* | 1.19.*, 1.20.* | 广泛使用版 |
| 3.4.* | 1.19.*, 1.20.* | — |
| 3.3.* | 1.18.*, 1.19.*, 1.20.*, 2.1.* | YAML Pipeline 正式可用 |
| 3.2.* | 1.17.*, 1.18.*, 1.19.*, 1.20.* | — |
| 3.1.* | 1.16.*, 1.17.*, 1.18.*, 1.19.* | — |
| 3.0.* | 1.14.*, 1.15.*, 1.16.*, 1.17.*, 1.18.* | 增量快照+动态加表 |
| 2.4.* | 1.13.*, 1.14.*, 1.15.*, 1.16.*, 1.17.* | 旧版稳定，不推荐新项目 |
